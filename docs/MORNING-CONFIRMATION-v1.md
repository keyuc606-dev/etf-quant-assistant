# 早盘二次确认与极简推送

## 确定性规则

只作用于真实账户盘中建议，不改 allocation/rebalance/backtest/持仓事实。最终枚举仍为 HOLD/ADD/REDUCE/RISK_EXIT/NO_ACTION/MANUAL_REVIEW。

- 中国时间09:30–10:00为LOW，10:00–11:00为MEDIUM，13:30–15:00为HIGH；其余时段保守LOW。时段信息不能覆盖RISK_EXIT。
- 新鲜日内低点反弹幅度为 price/low-1。保护门槛 clamp(0.5*ATR/price, 1%, 2%)；缺ATR用1%。低点缺失、非正或高于现价则unknown。达到门槛或重新收复关键位即保护。保护仅延后卖出，不授予ADD。
- 早盘普通REDUCE（含锁利和战术动作）默认映射为HOLD，保留条件份额，报告“先不减”。失效退出完全旁路等待。
- 单次报价不证明持续弱势。只有同日已验证先前观测间隔30–240分钟、两次都破趋势及支撑、相对收益继续恶化至少0.2个百分点、且没有反抽保护时，才允许早盘MEDIUM减仓。生产目前无09:xx额外采样，通常等待14:10。
- 条件价位来自已完成日K支撑和MA20：较低位为确认位，较高位为取消位；缺价位不生成模糊执行单。报告明确“无法核验则等14:10”，不要求用户11:00持续盯盘，也未新增推送。
- 14:10独立重跑原风险/基本面/估值/低吸闸门。修复则取消候选，弱势持续且原减仓闸门成立则确认。ADD仍需全部原有条件。

## 主推送

最多3个重点，失效退出优先，其次减仓、加仓、复核和早盘候选。同优先级按代码稳定排序。每项标题、结论、条件、原因共4行；原因由确定性规则翻译成人话。省略正常数据与技术字段。更多动作提示“另有N项候选见详细报告”，避免把被折叠的风险说成无需处理。

详细报告为所有新鲜报价保存完整诊断JSON及原分析，仍可使用表格。10:30 advice history保存time_of_day_confidence、rebound_from_low_pct、weakness_persistence、confirmation_state、conditional_quantity与morning_observation。版本改变使审计ID与旧版并存，旧记录不重写。

14:10在私有状态的closing_observations追加按advice_id关联的首份观测，保存后回读一致才推送；不修改原始10:30记录或真实持仓。使用现有共享云端状态锁与大文件读取机制。失败重试不覆盖首份观测。

# 基本面、估值与14:10执行计划

唯一动作引擎升级为 `final-decision-v3-fundamental`，动作枚举不变。仅改变账户执行建议，不改变周度配置、撮合、ETF V2回测、真实账户或成交。规则由确定性数据计算，AI不打分。

## 免费公开输入与降级

- 中证官方 `https://www.csindex.com.cn/csindex-home/perf/index-perf`：历史收盘、滚动PE（接口字段`peg`）、样本数量。字段依据现有AKShare的 `stock_zh_index_hist_csindex` 与实际响应核验。只使用建议日之前的完整记录。
- 股票复用东财财报接口 `RPT_F10_FINANCE_MAINFINADATA`：披露日严格早于建议日，净利润同比`PARENTNETPROFITTZ`、加权ROE `ROEJQ`；报告期超过150日则UNKNOWN。净利同比低于-5%或ROE非正为DETERIORATING；同比高于5%且ROE正为IMPROVING，其余为STABLE。缺任一字段UNKNOWN。股票估值历史暂缺可靠来源，因此UNKNOWN，不用固定行业PE中枢冒充历史分位，也不允许据此低吸。
- 所有请求仅在fetcher内；每次请求12秒超时，无额外重试；每指数/股票每天一次请求，包括失败冷却。JSON原子缓存，失败返回原日期快照；过期、未来、空值、代码不符均UNKNOWN。指数快照最长10个自然日（覆盖长假），不会重标旧数据日期。
- 指数估值：最多756个完整有效交易样本，至少252个且跨度330日；当日正PE在历史分布的中秩百分位。≤20为CHEAP，20–80为FAIR，80–95为EXPENSIVE，≥95为EXTREME。valuation_score=100-百分位。非正PE不判便宜；样本不足UNKNOWN。
- 指数基本面为**隐含盈利趋势代理**：指数收盘/滚动PE的21日均值，与63交易日前21日均值比较；变化<-5%恶化，>5%改善，其余稳定。至少84个样本、跨度≤150自然日且样本数量不变。样本数量变化/缺失UNKNOWN。该代理受成分替换、权重和除数变化影响，不能证明真实行业景气稳定，也不代表盈利预测、政策趋势或产业逻辑；报告明确标注“代理”。没有可靠产业周期、盈利预期数据时不编造这些维度。fundamental_score留空。

## 动作顺序与低吸闸门

失效位破坏始终RISK_EXIT。关键支撑破坏仍可REDUCE，不因“便宜”阻止硬风控。

技术弱、CHEAP、STABLE/IMPROVING且关键支撑未破：HOLD / LOW_BUY_WATCH，不因MA20或REL_WEAK直接砍仓。技术弱且昂贵+恶化：增强风险减仓确认。极贵或基本面恶化禁止新增追高ADD。

低吸必须CHEAP/FAIR + STABLE/IMPROVING；UNKNOWN、EXPENSIVE/EXTREME、DETERIORATING均阻断。还必须通过原超跌、支撑、收复、相对强弱、量价、ATR、失效位、风险收益、现金、仓位、总权益暴露、整手和经济性门槛。成本价不是加仓依据。LOW_BUY_WATCH是观察状态，不增加动作枚举。

合成通信ETF示例（不代表当前市场或真实持仓）：价格97、MA20=100、失效位90、支撑96，显著跑输上涨基准。旧版因独立弱势可能REDUCE；新版历史估值CHEAP、盈利代理STABLE且支撑未破时HOLD/LOW_BUY_WATCH。相对转稳、日内收复、买入区及全部账户闸门通过后才小仓ADD。价格89时无论估值如何仍RISK_EXIT。

## 报告、历史与推送

10:30和14:10主屏最多5条，原因包含基本面代理、估值与动作依据。详情分别展示价格位置、均线结构、最终动作、基本面、估值、低吸状态。历史新增版本、来源、截止日、分位、评分（可空）、映射降级、低吸状态、技术基本面冲突及最终动作；不保存完整历史序列。月报CSV保留这些字段并按基本面/估值/低吸分组。旧记录保留空值，另标fundamental_record_quality=legacy/partial，绝不回填猜测。

尾盘工作流cron为 `10 6 * * 1-5`（UTC06:10=北京时间14:10）。名称“尾盘提前执行计划”，仍保留交易日门禁、account-cloud-state并发锁。当时行情为provisional，不代表收盘；展示实际报价时间，过期报价直接降级，不生成强动作。14:10后未成交不追价，按条件单人工执行。09日一次性补发工作流保留原历史时间文案。
